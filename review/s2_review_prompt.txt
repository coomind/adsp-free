다음은 ADsP(데이터분석 준전문가) 2과목 '데이터분석 기획' 대비로 직접 만든 4지선다 예상문제 30개입니다. 각 문제에 우리가 정한 정답과 해설을 붙였습니다.

요청: 틀리거나, 애매하거나, 복수정답인 문제를 찾아 주세요. 문제가 없다고 판단하더라도 가장 약한 3문제를 골라 이유와 함께 알려 주세요.
답변 형식: [문제 ID] 판정(정답오류/복수정답/애매/해설오류/약함) - 이유 - 수정 제안

[s2-001] KDD(Knowledge Discovery in Databases) 분석 절차의 순서로 옳은 것은?
  ① 데이터셋 선택 → 전처리 → 변환 → 데이터 마이닝 → 결과 해석·평가
  ② 전처리 → 데이터셋 선택 → 데이터 마이닝 → 변환 → 결과 해석·평가
  ③ 데이터셋 선택 → 변환 → 전처리 → 결과 해석·평가 → 데이터 마이닝
  ④ 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가
  정답: ① / 해설: KDD는 선택(Selection) → 전처리(Pre-processing) → 변환(Transformation) → 데이터 마이닝 → 해석·평가 순이다. ④는 CRISP-DM의 앞 5단계다.

[s2-002] KDD 절차에서 잡음(noise)이 있거나 값이 빠진 관측치를 정리하는 단계는?
  ① 데이터셋 선택
  ② 전처리
  ③ 변환
  ④ 결과 해석·평가
  정답: ② / 해설: 전처리 단계에서 목표 데이터셋을 정제(cleaning)해 잡음과 결측 관측치를 처리한다.

[s2-003] KDD 절차의 첫 단계는?
  ① 데이터셋 선택
  ② 데이터 마이닝
  ③ 결과 해석·평가
  ④ 변환
  정답: ① / 해설: KDD는 분석 대상이 될 데이터셋을 선택하는 단계(Selection)로 시작한다.

[s2-004] KDD 절차의 마지막 단계는?
  ① 전처리
  ② 결과 해석·평가
  ③ 데이터 마이닝
  ④ 변환
  정답: ② / 해설: 마지막은 마이닝 결과를 해석하고 평가하는 단계(Interpretation/Evaluation)다.

[s2-005] CRISP-DM의 6단계 순서로 옳은 것은?
  ① 업무 이해 → 데이터 준비 → 데이터 이해 → 모델링 → 전개 → 평가
  ② 데이터 이해 → 업무 이해 → 모델링 → 데이터 준비 → 평가 → 전개
  ③ 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개
  ④ 데이터 준비 → 데이터 이해 → 업무 이해 → 모델링 → 평가 → 전개
  정답: ③ / 해설: CRISP-DM은 업무 이해(Business Understanding) → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개(Deployment)의 6단계다.

[s2-006] CRISP-DM의 첫 단계는?
  ① 데이터 이해
  ② 모델링
  ③ 데이터 준비
  ④ 업무 이해
  정답: ④ / 해설: CRISP-DM은 업무 이해(Business Understanding)로 시작한다.

[s2-007] CRISP-DM의 마지막 단계는?
  ① 전개
  ② 모델링
  ③ 평가
  ④ 데이터 준비
  정답: ① / 해설: 마지막 단계는 전개(Deployment)다.

[s2-008] CRISP-DM에 대한 설명으로 옳은 것은?
  ① 단계 순서가 엄격해 앞 단계로 되돌아갈 수 없다
  ② 단계 사이를 오가는 피드백이 흔히 필요하다
  ③ 모델링 다음 단계는 전개다
  ④ KDD와 같은 5단계로 구성된다
  정답: ② / 해설: CRISP-DM의 단계 순서는 엄격하지 않으며 단계 사이를 앞뒤로 오가는 것이 보통 필요하다. 모델링 다음은 평가이고, 6단계로 구성된다.

[s2-009] 다음 중 CRISP-DM의 단계가 아닌 것은?
  ① 업무 이해
  ② 데이터 준비
  ③ 데이터 변환
  ④ 전개
  정답: ③ / 해설: '변환(Transformation)'은 KDD의 단계다. CRISP-DM은 업무 이해·데이터 이해·데이터 준비·모델링·평가·전개다.

[s2-010] CRISP-DM에서 '모델링' 바로 다음 단계는?
  ① 데이터 준비
  ② 업무 이해
  ③ 전개
  ④ 평가
  정답: ④ / 해설: 모델링 다음은 평가(Evaluation), 그다음이 전개다.

[s2-011] CRISP-DM에서 '데이터 이해' 바로 다음 단계는?
  ① 데이터 준비
  ② 모델링
  ③ 업무 이해
  ④ 평가
  정답: ① / 해설: 데이터 이해 다음은 데이터 준비(Data Preparation)다.

[s2-012] SAS가 제시한 데이터 마이닝 방법론 SEMMA의 순서로 옳은 것은?
  ① Explore → Sample → Model → Modify → Assess
  ② Sample → Explore → Modify → Model → Assess
  ③ Sample → Modify → Explore → Assess → Model
  ④ Select → Explore → Mine → Model → Assess
  정답: ② / 해설: SEMMA는 Sample(추출) → Explore(탐색) → Modify(수정) → Model(모델링) → Assess(평가)다.

[s2-013] SEMMA 방법론의 첫 단계는?
  ① Sample
  ② Explore
  ③ Modify
  ④ Assess
  정답: ① / 해설: SEMMA는 모델링용 데이터셋을 추출하는 Sample 단계로 시작한다.

[s2-014] 각 단계의 결과가 다음 단계의 입력이 되어 순차적으로 진행되고, 앞 단계로 되돌아가기 어려운 모델은?
  ① 프로토타입 모델
  ② 나선형 모델
  ③ 폭포수 모델
  ④ 반복적 모델
  정답: ③ / 해설: 폭포수(Waterfall) 모델은 단계가 한 방향으로 순차 진행되어 반복·유연성이 가장 낮은 편이다.

[s2-015] 위험(risk)을 중심으로 반복하며 개발을 진행하는 모델은?

  정답: ④ / 해설: 나선형(Spiral) 모델은 위험 중심(risk-driven)의 반복적 개발 모델이다.

[s2-016] 요구사항이 불명확할 때 불완전한 시제품을 빠르게 만들어 사용자 피드백을 받으며 개선하는 접근은?

  ④ 나선형 모델
  정답: ① / 해설: 프로토타이핑은 미완성 버전을 먼저 만들어 초기에 사용자 피드백을 받고 요구사항을 구체화한다.

[s2-017] 폭포수 모델에 대한 설명으로 옳은 것은?
  ① 요구사항을 초기에 확정하기 어려운 과제에 가장 적합하다
  ② 후반에 요구사항이 바뀌면 재설계·재개발 비용이 커진다
  ③ 위험 분석을 매 반복마다 수행하는 것이 핵심이다
  ④ 시제품을 먼저 만들어 사용자 피드백을 받는다
  정답: ② / 해설: 폭포수 모델은 순차 진행이라 뒤늦은 요구사항 변경이 재설계·재개발·재시험으로 이어져 비용이 커진다. 위험 중심 반복은 나선형, 시제품 피드백은 프로토타입 모델의 특징이다.

[s2-018] 해결할 문제가 주어진 상태에서 전체 문제를 작은 하위 문제로 나누어 해법을 찾아 가는 접근 방식은?
