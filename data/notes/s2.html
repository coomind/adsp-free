분석 방법론 근거

KDD (Knowledge Discovery in Databases)

순서단계한 줄
1데이터셋 선택(Selection)분석 대상 데이터를 고른다
2전처리(Pre-processing)잡음·결측 관측치를 정제한다
3변환(Transformation)분석에 맞게 변수를 바꾸고 줄인다
4데이터 마이닝패턴을 찾는다
5결과 해석·평가찾은 패턴을 해석·평가한다

CRISP-DM — 6단계, 단계 사이를 앞뒤로 오갈 수 있다(순서가 엄격하지 않음). 조사에서 가장 널리 쓰인 방법론.

순서단계
1업무 이해 (Business Understanding)
2데이터 이해 (Data Understanding)
3데이터 준비 (Data Preparation)
4모델링 (Modeling)
5평가 (Evaluation)
6전개 (Deployment)

SEMMA (SAS): Sample → Explore → Modify → Model → Assess

개발 모델핵심
폭포수(Waterfall)단계를 순차 진행, 뒤늦은 요구사항 변경 시 재작업 비용이 큼
나선형(Spiral)위험(risk) 중심으로 반복
프로토타입미완성 시제품으로 초기에 사용자 피드백을 받아 요구사항 구체화

마스터 플랜 수립 교재 정리

  • 분석 과제의 우선순위는 보통 시급성(전략적 중요도)과 난이도(실행 용이성)를 함께 보고 정한다.
  • 중장기 로드맵은 단계적으로 분석 과제를 확산하는 순서로 짠다.

분석 거버넌스 체계 수립

근거 데이터 거버넌스: 조직의 데이터를 효과적이고 책임 있게 쓰도록 이끄는 원칙·정책·프로세스의 집합. 데이터 품질, 메타데이터 관리, 마스터 데이터 관리, 접근 통제, 생애주기 관리 등을 다룬다.

용어뜻
마스터 데이터 관리(MDM)고객·상품·계좌처럼 공유하는 핵심 데이터를 일관되고 정확하게 관리
데이터 사전데이터의 의미·관계·출처·용도·형식을 모은 중앙 저장소

근거 CMMI 성숙도 5단계: 초기(Initial) → 관리(Managed) → 정의(Defined) → 정량적 관리(Quantitatively Managed) → 최적화(Optimizing)

교재 정리 분석 성숙도는 도입 → 활용 → 확산 → 최적화 단계로, 분석 조직 구조는 집중형·기능형·분산형으로 나눠 설명한다.
